Voidlight Arena — a complete original 2D canvas arena-survival shooter. You are a lantern-ship holding the light in a dark arena: move with WASD or arrow keys, aim with the mouse, and survive 10 escalating waves of wisps, weavers, spitters, splitters and brutes to become Arena Champion. Combo scoring up to x5, power-up drops, particles, screen shake, synthesized sound effects and music, pause, victory and game-over screens with restart.

## Run it

```sh
npx --yes serve game
```

Then open http://localhost:3000 in desktop Chrome. Or open `game/index.html` directly — the game plays fully offline, no network requests.
